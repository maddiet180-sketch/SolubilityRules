# SolubilityRules

An educational iOS app aimed at helping high school and college students understand the logic behind "arbitrary" solubility rules in chemistry.

- **Learn**: predict the solubility of compounds in a drag-and-drop mini game
- **Explore**: visualize solubility trends using predictive machine learning models
